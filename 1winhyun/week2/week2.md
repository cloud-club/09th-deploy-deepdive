# Architecture

## 목표
1. 졸업 프로젝트 내 인프라 구축
2. ASG(Auto Scaling Group) + ALB + EC2를 이용한 서버 인프라 구축. 실제 운영 환경에서 사용자 트래픽을 고려한 오토 스케일링을 갖춘 서버 구축.
